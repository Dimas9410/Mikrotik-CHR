# Mikrotik-CHR
This is a script to automatically install Mikrotik Chr on Ubuntu versions 20.04, 22.04, and 24.04.

# Usage
```
sudo su
```
```
git clone -b chr-v7 https://github.com/Dimas9410/Mikrotik-CHR.git
```
```
cd Mikrotik-CHR
```
```
chmod +x install.sh
```
```
apt update
```
```
apt-get install dos2unix
```
```
dos2unix install.sh
```
```
bash install.sh
```
